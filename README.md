# Utah Wetland Data Explorer

TanStack Start app replicating the Utah Wetlands Data Explorer R Shiny dashboard.

## Setup

```bash
npm install
npm run dev
```

## Tech Stack

- TanStack Start (React, file-based routing)
- Tailwind CSS
- D3.js (charts)
- MapLibre GL (maps)
- PostgREST backend

## Environment

Copy `.env.example` to `.env` and configure API settings if needed.
